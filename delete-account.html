Account Deletion Request

Delete Your SKILL UP Account

SKILL UP is a mobile language-learning application that helps users practice and improve their language skills. If you no longer wish to use SKILL UP, you may request deletion of your account and associated personal data.

You can submit a request even if you no longer have the application installed on your device.

How to Request Account Deletion

  1. Send an email to the official SKILL UP support email address listed by the developer.
  2. Use the subject line: SKILL UP Account Deletion Request.
  3. Include the email address associated with your SKILL UP account so the developer can identify the account.
  4. The developer may request reasonable information to verify account ownership before processing the request.

Do not send your password, verification codes, or other authentication secrets by email.

Data That May Be Deleted

After a verified deletion request is approved, the developer will delete the account and associated data that is covered by the deletion request and is not required to be retained.

  • SKILL UP account and profile information.
  • Learning progress and assessment records associated with the account.
  • Other personal information associated with the account, where applicable.

Account deletion should also address associated Firebase Authentication records and applicable user data stored in Cloud Firestore and Firebase Storage.

Data Retention

Some information may be retained only when required by law, necessary for security, or needed to resolve legitimate disputes. Any retained data should be limited to what is necessary and kept only for the applicable retention period.

Processing time and retention period: The developer must specify the actual timeframe for processing deletion requests and any applicable retention period before publishing this page.

Delete Specific Data Without Deleting Your Account

If you want to request deletion of specific personal data without deleting your entire account, contact the developer using the support email above and describe the data you want deleted. The developer will review the request and explain which data can be deleted while keeping the account active.
